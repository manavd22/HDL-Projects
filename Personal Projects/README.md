# Personal Verilog Projects

Digital design projects in Verilog HDL, covering FSM-based control and arithmetic hardware. Each project includes RTL design and a testbench, simulated in Xilinx Vivado.

---

## 1. Traffic Light Controller

A 4-way intersection controller built as an 8-state Moore FSM.

- Pedestrian crossing requests (NS/EW)
- Emergency vehicle override with highest priority
- Parameterizable green, yellow and red timing
- Enable/disable control with state freeze
- 100% state coverage in verification

**Skills:** FSM design · Safety-critical control logic · Separation of sequential and combinational logic

---

## 2. Booth's Algorithm Multiplier

A radix-2 Booth multiplier for signed (two's complement) numbers.

- Parameterizable width (8/16/32 bits)
- FSM-based control architecture
- Compact, readable RTL

**Skills:** Arithmetic algorithm implementation · Signed number handling · Datapath and control design
